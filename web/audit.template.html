Does a model beat size alone?

This table has a column that could be a model's predicted score. If it is, the check below reports what a predictor that sees only how big each set is scores on your own evaluation, next to yours. The size-only baseline is leave-one-out, so it never saw the row it predicts.

The metric is asked for, never inferred — a baseline scored with a different metric than yours is not a comparison.

Look up a published screen's floor

The atlas carries the no-biology floor for __ATLAS_N__ published human CRISPR screens — the share of each one's gene-set ranking that set size alone predicts.
